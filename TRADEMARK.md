# Trademark

This file covers the **equuid** name and any logo or wordmark used for the
project. It does not restate the software license — that is in
[`LICENSE-MIT`](LICENSE-MIT) and [`LICENSE-APACHE`](LICENSE-APACHE) — except on
the one point where the two are easy to confuse, the copyright in a logo file
itself. It is not a statement about anyone else's marks.

## The code license grants no trademark rights

equuid is offered under `MIT OR Apache-2.0`. Those licenses grant copyright
rights, and Apache-2.0 additionally grants patent rights. **Neither grants
trademark rights.** Apache-2.0 §6 says so explicitly: the license does not grant
permission to use the trade names, trademarks, service marks, or product names
of the licensor, except as required for reasonable and customary use in
describing the origin of the work and reproducing the content of the NOTICE
file. MIT is silent on the subject, which is not a grant either.

Trademark rights in the name are held by the project's maintainer, Kenneth
Rawlings, separately from the copyright in the code and any artwork.

## Copyright in the artwork

There is no logo or wordmark file in this repository yet.

If one lands, the maintainer holds its copyright and will offer it under the
same `MIT OR Apache-2.0` grant as the rest of the project: you would be able to
copy, modify and redistribute it with the project, under either license.

Copyright and trademark are different rights, and that grant is only the first
of them. It would give you the file; it would give you no right to use the logo
as a mark. The permissions and prohibitions below govern that, and they apply to
a logo exactly as they apply to the name.

## What you may do without asking

**Nominative use** — using the name, or any logo, to refer to this project
truthfully:

- "generate a v7 with equuid", "equuid rejects a misplaced hyphen"
- "based on equuid", "a fork of equuid", "compatible with equuid"
- redistributing the software, modified or not, under the terms of either
  license, with the copyright material those licenses require

You do not need permission to say what the software is, what it does, or what
you built with it.

## What you may not do

- Use the name as the name of a modified version or fork in a way that suggests
  your version *is* this project or comes from it. Rename your fork.
- Use the name or any logo in a way that implies endorsement, sponsorship, or
  affiliation that does not exist.
- Register the name, a confusingly similar name, or a logo as a trademark,
  domain name, package name, or organization name.

The crate and binary are published as `equuid`. A fork that keeps the name but
changes the behavior is exactly the case the first rule is about.

## Forks

Fork freely — that is what the licenses are for. If you distribute a modified
version, rename it, and keep the attribution the licenses require: the MIT
copyright notice, and for Apache-2.0 §4(a)–(d), the license text, the modified
files marked as changed, and a statement of the changes you made.

## On the absence of a NOTICE file

There is no `NOTICE` file in this repository, and that is a decision rather than
an omission. Apache-2.0 §4(d) requires retaining a `NOTICE` only when the work
carries one; equuid is written from scratch and redistributes nothing. If this
project ever vendors or derives from someone else's work, the file appears with
the attribution that work requires.
